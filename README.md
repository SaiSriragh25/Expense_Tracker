# Expense Tracker – Python Full Stack Project

A simple and user-friendly Expense Tracker web application built using Python Flask, SQLite, HTML, and CSS.

## 🚀 Features
- Add daily expenses
- Edit existing expenses
- Delete expenses
- Filter expenses by category and date
- Calculate total expenses
- Input validation with error messages
- Flash messages for user actions
- Clean and responsive UI

## 🛠 Tech Stack
- Frontend: HTML, CSS
- Backend: Python (Flask)
- Database: SQLite
